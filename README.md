# 🌐 Portfolio - Ayanleh Osman Houssein

Portfolio personnel développé afin de présenter mon parcours, mes compétences en développement web ainsi que mes différents projets réalisés.

Ce site permet de découvrir mon profil, mes expériences, mes formations et mes réalisations dans le domaine du développement web.

---

## 📌 Description du projet

Ce projet consiste à créer un site portfolio responsive permettant de présenter :

- Mon parcours académique ;
- Mes compétences techniques ;
- Mes expériences en développement web ;
- Mes projets réalisés ;
- Mes informations de contact.

Le site a été conçu avec une approche responsive afin d'assurer une bonne expérience utilisateur sur ordinateur, tablette et mobile.

---

## 🚀 Fonctionnalités

- Navigation avec défilement entre les différentes sections.
- Présentation du profil personnel.
- Section compétences avec indicateurs de progression.
- Présentation des expériences professionnelles.
- Présentation du parcours académique.
- Galerie de projets réalisés.
- Section recommandations.
- Formulaire de contact.

---
